우리집 가계부 3종 사용설명서

세 가계부 모두 인터넷 주소로 열어요. 화면과 기본 기능은 같고, 내역을 어디에 저장하고 가족과 어떻게 나누는지가 달라요.

세 가계부 접속 방법

1함께 쓰는 가계부

서버에 저장 · 가족이 실시간으로 같이 봐요
household-ledger-one-iota.vercel.app
예비 주소: skyguslee-cloud.github.io/household-ledger/
안드로이드는 설치 파일(APK)로도 쓸 수 있어요.
  1. 관리자에게 받은 초대 링크를 누르면 바로 들어가요.
  2. 또는 별칭 주소(주소/#별칭)를 열고 숫자 비밀번호를 한 번 넣어요.
  3. 누구세요? 창에서 내 이름을 골라요.
이런 가족에게: 모두 인터넷이 잘 되고, 적자마자 서로 보고 싶을 때

2구글 시트 가계부

휴대폰에 먼저 저장 → 가족 구글 시트와 주고받아요
skyguslee-cloud.github.io/sheet-ledger/
  1. 관리자 한 명이 구글 시트를 만들어 연결해 둬요. (약 10분, 처음 한 번)
  2. 가족은 관리자가 보낸 가족 초대 링크를 눌러요.
  3. 누구세요?에서 이름을 고르고, 처음 비밀번호 = 내 이름을 넣은 뒤 새 비밀번호로 바꿔요.
이런 가족에게: 서버 없이 가족 공유는 하고 싶고, 엑셀처럼 시트로도 보고 싶을 때

3각자 가계부

내 휴대폰에만 저장 · 파일로 모아서 합쳐 봐요
skyguslee-cloud.github.io/each-ledger/
  1. 주소를 열고 내 이름만 넣으면 바로 시작해요.
  2. 연결·비밀번호 설정이 없어요.
  3. 가족 합계가 보고 싶으면 각자 통합용 파일을 한 사람에게 보내요.
이런 가족에게: 각자 따로 쓰고, 월말에 한 번 모아 보면 충분할 때

1함께 쓰는 가계부 — 처음 시작하기

  1. 관리자에게 받은 초대 링크를 휴대폰에서 눌러요.
  2. 누구세요? 창이 뜨면 내 이름을 눌러요.
  3. 홈 화면에 추가해요. (안드로이드는 받은 APK 파일을 설치해도 돼요)
  4. 홈 화면 아이콘으로 열었는데 연결 칸이 보이면, 별칭과 숫자 비밀번호를 넣어요.

✔ 맨 위에 ● 실시간이 보이면 잘 연결된 거예요. 가족이 적은 내역이 바로 보여요.

처음부터 내 가족 가계부를 새로 만들고 싶다면: 시작 화면 아래 새 가계부 사용 신청하기에 메일 주소를 남기면 관리자 승인 후 메일로 안내가 와요.

2구글 시트 가계부 — 처음 시작하기

가족(관리자가 아닌 분)은 이렇게만 하면 돼요.

  1. 관리자가 카톡으로 보낸 가족 초대 링크를 눌러요.
  2. 먼저 홈 화면에 추가하고, 홈 화면 아이콘으로 다시 열어요.
    아이폰은 아이콘으로 처음 열면 첫 칸에 초대 링크를 통째로 붙여넣어 주세요.
  3. 누구세요?에서 내 이름을 골라요.
  4. 처음 비밀번호는 내 이름이에요. 넣으면 바로 나만 아는 새 비밀번호를 정해요.

✔ 맨 위 작은 글자가 동기화됨이면 잘 연결된 거예요. "보낼 것 N건"은 인터넷이 되면 자동으로 올라가요.

2부. 자세한 설명서

메뉴별 기능을 모두 정리했어요. 앞쪽은 세 가계부 공통, 뒤쪽은 가계부마다 다른 기능이에요.

A. 공통 기능

홈 아래 홈

  • 이번 달 지출·수입을 분류별 블록으로 보여요. 큰 금액은 "160만원"처럼 짧게 보여요.
  • 블록을 누르면 정확한 금액과 누가·어떻게(카드·현금 등) 썼는지 펼쳐져요. ✎로 고치고 🗑로 지워요.
  • 매달 25일부터 월말 결산 알림, 오래 백업하지 않았으면 백업 알림이 홈에 떠요.

내역 추가 가운데 ＋

  • 지출/수입 고르기, 금액, 분류, 사용처·메모, 결제 수단, 날짜를 적어요.
  • 같은 가게를 한 번 분류해 두면 다음부터 그 분류가 자동으로 골라져요.
  • 다른 사람 이름으로 적기는 가계부마다 허용 방식이 달라요(뒤쪽 B 참고).

내역 · 검색 아래 내역

  • 전체 목록을 사람별, 수입/지출별로 골라 봐요. 분류별·사용자별 지출 합계도 함께 보여요.
  • 🔍 검색 칸에 사용처·분류·금액(예: 스타벅스, 45000)을 넣으면 모든 달에서 찾아 건수와 합계를 보여줘요.
  • 다른 해의 내역은 날짜가 "25.03.14"처럼 연도와 함께 보여요.

카드·은행 문자로 넣기 더보기 → 문자로 넣기 ＋ → 카드·은행 문자로 넣기

  1. 카드 승인·입출금 문자(카톡 알림)를 길게 눌러 복사해요. 여러 건을 한꺼번에 복사해도 돼요.
  2. 붙여넣기 → 인식하기.
  3. 인식 결과에서 넣을 것만 체크하고 선택 항목 추가.

예산 아래 예산

  • 월간 예산: 분류별 한 달 예산을 적어요. 새 달이 되면 지난달 예산이 이어지고, 고친 칸만 그 달에 적용돼요.
  • 막대 색: 회색(여유) → 검정(80% 넘음) → 빗금(초과).
  • 연간 예산: 여행, 경조사·명절, 미용, 옷, 자동차보험·세금, 재산세, 가전·가구는 1년 단위로 따로 관리해요.
  • 월말 결산: 이번 달 쓴 돈을 확인하고, 최근 3개월 지출을 바탕으로 추천한 금액으로 다음 달 예산을 정해요.

우리 가족 조건 · 예산 추천 더보기 → 우리 가족 조건 예산 → 가족 조건으로 추천

  • 어른·아이 수와 학년, 사는 곳, 집(자가·전세 등), 차, 수입, 저축 목표를 넣으면 분류별 예산을 추천해요.
  • 추천된 칸을 고쳐서 저장하면 돼요. 조건은 언제든 바꿀 수 있어요.

고정 수입·지출 더보기 → 고정 수입·지출 · 카드 할부

  • 월급, 관리비, 통신비처럼 매달 같은 날 생기는 돈을 등록하면 그날 자동으로 기록돼요.
  • 금액이 바뀌면 금액 변경에서 "이번 달부터 / 다음 달부터"를 골라요. 지난 기록은 그대로예요.

💳 카드 할부 같은 화면 아래쪽

  • 물건 이름, 총 금액, 개월 수, 첫 청구 달, 청구일, 분류, 사람, 결제 수단을 넣고 등록해요.
  • 매달 청구액이 자동 기록돼요. 나누어 떨어지지 않는 금액은 첫 달에 더해요. (예: 1,000,005원 12개월 → 첫 달 83,342원, 이후 83,333원)
  • 목록에 "3/12회차", 남은 금액, 진행 막대가 보이고, 내역에는 할부 3/12 표시가 붙어요.
  • 이미 지난 달부터 시작했다면 "지난 회차도 기록"을 체크하면 지난 달 것도 넣어요.
  • 미리 다 갚았다면 중도 완납 → 남은 금액이 한 건으로 기록되고 할부가 끝나요.

개인별 통계 더보기 → 개인별 통계

  • 사람을 고르면 그 사람의 이번 달 수입·지출, 분류별 지출, 최근 6개월 지출, 많이 쓴 곳, 올해 합계, 가족 비교를 보여줘요.

📥 엑셀·다른 가계부 가져오기 더보기 → 엑셀·다른 가계부 가져오기

  1. 다른 가계부 앱, 은행·카드사에서 받은 엑셀(.xlsx/.xls) 또는 CSV 파일을 골라요.
  2. 열 맞추기: 날짜·금액·내용·분류 등 어느 열인지 자동으로 찾아요. 틀린 칸만 바꿔요. 시트가 여러 개면 시트도 골라요.
  3. 누구 내역으로 넣을지, 금액에 +가 붙은 것을 수입으로 볼지 정해요.
  4. 미리보기에서 확인하고 추가. 이미 있는 내역(같은 날·금액·내용)은 자동으로 건너뛰어요.

은행 CSV는 한글이 깨지는 형식(EUC-KR)도 알아서 읽어요. 한 번에 5,000건까지 넣을 수 있어요.

백업 · 내보내기 더보기 → 설정 → 백업 · 내보내기

  • 전체 백업 (JSON): 가계부 전체를 파일 하나로 저장해요. 휴대폰에서는 카톡·메일·드라이브로 보내는 창이 떠요.
  • 백업 불러오기: 백업 파일 내용으로 지금 가계부를 바꿔요. 신중하게 쓰세요.
  • CSV 내보내기: 엑셀에서 열 수 있는 표 파일로 내보내요.

설정 · 기타 더보기 → 설정

  • 사용자 이름: 가족 이름을 바꾸고, 캐릭터를 눌러 나를 나타낼 이모지를 골라요.
  • 위험 구역: 이 기기 연결 해제/지우기, 전체 데이터 삭제. 누르기 전에 꼭 백업하세요.
  • 맨 위 내 이름을 누르면 "누구세요?"를 다시 골라요.

B. 가계부마다 다른 기능

1함께 쓰는 가계부

들어가는 방법 3가지

  • 초대 링크: 설정 → 가계부 공유 → 초대 링크 복사로 만든 링크. 열자마자 같은 가계부에 연결돼요. 링크가 있으면 누구나 볼 수 있으니 가족에게만 보내세요.
  • 별칭 주소: 설정 → 별칭 주소에서 한글·영문 소문자·숫자 1~4글자로 정해요. 주소/#별칭으로 열고 숫자 비밀번호를 한 번 넣으면 돼요. 비밀번호를 5번 틀리면 잠시 잠겨요.
  • 가계부 키 직접 넣기: 시작 화면 연결 칸에 키나 별칭을 넣어요.

● 실시간 반영

  • 가족이 저장하면 다른 휴대폰에도 바로 바뀌어요. 맨 위에 ● 실시간이 보이면 연결된 상태예요.
  • 내가 입력 중일 때는 다 쓰고 나서 화면이 바뀌어요. 1분마다 자동 새로고침도 해요.

여러 가계부 쓰기

  • 맨 위 가계부 이름(▾)을 눌러 다른 가계부로 바꾸거나 ＋ 다른 가계부 추가를 눌러요. 별칭으로도 추가할 수 있어요.
  • 가계부마다 "내 이름"을 따로 기억해요. 목록에서 이름 바꾸기·목록에서 빼기도 돼요.

새 가계부 신청 · 안드로이드 앱

  • 시작 화면 새 가계부 사용 신청하기에 메일 주소를 남기면, 관리자 승인 후 가계부 키를 메일로 받아요.
  • 안드로이드는 관리자에게 받은 설치 파일(APK)로 일반 앱처럼 설치할 수 있어요. 처음 열면 별칭과 비밀번호를 넣어요.
  • 다른 사람 이름으로 적기는 정해진 관리자만 할 수 있어요.
무료 인터넷 서버를 쓰고 있어요. 한 달에 한 번 전체 백업을 해 두면 서버에 문제가 생겨도 되살릴 수 있어요.

2구글 시트 가계부

관리자: 구글 시트 만들기 (처음 한 번, 컴퓨터로 약 10분)

  1. sheets.new를 열어 새 구글 시트를 만들어요. 이름 예: 우리집 가계부.
  2. 메뉴 확장 프로그램 → Apps Script를 열어요.
  3. Code.gs 내용을 모두 지우고, 앱 만든 사람에게 받은 Code.js 내용을 통째로 붙여넣어요.
  4. 맨 위 var FAMILY_CODE = '…'; 따옴표 안을 가족 비밀번호(4글자 이상)로 바꿔요.
  5. 💾 저장 → 함수 칸에서 setup → ▶ 실행. 권한 창이 뜨면 내 계정 → 고급 → (안전하지 않음)으로 이동 → 허용.
    직접 만든 스크립트라 뜨는 경고예요. 이 시트만 읽고 써요.
  6. 시트 아래에 entries, settings 탭이 생기면 성공이에요.
  7. 배포 → 새 배포 → ⚙ 웹 앱 → 실행 사용자: 나, 액세스: 모든 사용자 → 배포 → 웹 앱 URL을 복사해요.
  8. 휴대폰에서 앱 주소를 열고 홈 화면에 추가 → 아이콘으로 열어 웹 앱 URL과 가족 비밀번호를 넣고 구글 시트에 연결.
  9. 더보기 → 설정에서 가계부 이름, 가족 이름(가족1~가족5), "다른 사람 것도 입력"할 사람을 정해요.
  10. 설정 → 가족 초대 링크 복사 → 카톡으로 가족에게만 보내요.

주고받기(동기화)

  • 입력하면 먼저 휴대폰에 저장되고, 저장할 때와 1분마다 시트와 주고받아요. 실시간은 아니에요.
  • 맨 위 작은 글자: 동기화됨 / 보낼 것 N건. 글자를 누르면 바로 주고받아요.
  • 같은 내역을 두 사람이 고치면 나중에 고친 쪽이 남아요.
  • 시트에서 금액·메모를 직접 고쳐도 휴대폰에 반영돼요. 줄은 지우지 말고 deleted 칸에 1을 넣으세요.

사람마다 비밀번호

  • 누구세요?에서 이름을 고를 때 각자 비밀번호를 넣어요. 처음 비밀번호는 자기 이름이고, 바로 새 비밀번호로 바꿔요.
  • 잊었으면 "다른 사람 것도 입력"에 체크된 가족이 설정 → 사용자 이름에서 초기화 → 다시 이름으로 돌아가요.

설정 메뉴 (구글 시트 연결)

  • 지금 주고받기, 가족 초대 링크 복사, 연결 바꾸기(다른 시트로), 연결 끊기.
  • 연결 바꾸기 때 "이 내역을 새 시트로 옮길까요?" — 다른 가족 시트면 취소(옮기지 않기), 우리 가족이 시트를 새로 만든 거면 확인(옮기기).
  • "이 휴대폰의 가계부 지우기"는 이 기기만 비우고 시트는 그대로예요. "전체 데이터 삭제"는 시트와 가족 휴대폰에서도 지워요.
  • 시트 없이 이 휴대폰에서만 쓰기도 돼요. 나중에 시트에 연결하면 그동안 적은 내역도 함께 올라가요.

다른 가족에게 나눠주기

  • 앱 주소는 모두 같고, 가족마다 자기 구글 시트를 연결해요. 그래서 가족끼리 내역이 섞이지 않고, 앱 만든 사람도 볼 수 없어요.
  • 보내줄 것은 앱 주소와 Code.js 파일 두 가지예요. 그 가족 관리자가 위 "구글 시트 만들기"를 똑같이 해요.

3각자 가계부

나만의 가계부

  • 처음 열면 내 이름만 물어요. 서버·계정·비밀번호·시트 연결이 없어요.
  • 아이 용돈처럼 대신 적어 줄 사람이 있으면 더보기 → 설정 → 가계부 이름 · 사람에 이름을 넣어요.
  • 인터넷이 없어도 적을 수 있어요. (말로 적기만 인터넷이 필요해요)

🎤 말로 적기

  • 위쪽 🎤 또는 ＋ 창의 말로 입력을 누르고 말해요.
  • 예: "어제 점심 김밥천국 만이천원", "스타벅스 사천오백원 카드로", "월급 삼백만원 들어왔어".
  • 날짜(오늘·어제·그저께·15일·금요일), 금액, 분류, 내용, 수입/지출이 자동으로 채워져요. 확인하고 저장을 눌러야 저장돼요.
  • 크롬(안드로이드·PC)과 아이폰 사파리에서 돼요. 처음 한 번 마이크 허용을 눌러 주세요.

👪 가족 통합 보기 더보기 → 가족 통합 보기

  • 내 파일 보내기: 통합용 파일(JSON)을 만들어 카톡·메일로 모아 볼 사람에게 보내요.
  • 받은 파일 넣기: 받은 파일을 골라요. 여러 파일을 한 번에 골라도 돼요.
  • 같은 사람의 새 파일을 넣으면 최신 내용으로 통째로 바뀌어 겹치지 않아요. 더 예전 파일은 무시해요.
  • 가족 전체 수입·지출, 분류별 지출과 누가 썼는지, 이 달 내역을 보여줘요.
  • 받은 내역은 보기만 해요. 2주 넘은 파일은 표시가 붙어요. 월말처럼 날을 정해 보내면 편해요.
각자 가계부는 휴대폰에만 저장돼요. 7일마다 뜨는 백업 알림을 따르고, 아이폰은 꼭 홈 화면 아이콘으로만 쓰세요. 사파리에서 오래 안 열면 저장 내용이 지워질 수 있어요.

자주 묻는 질문

1함께 쓰는 가계부

가족이 적은 게 안 보여요.
맨 위 "동기화" 글자를 누르면 새로고침돼요. ● 실시간이 안 보이면 인터넷 연결을 확인하세요.
새 휴대폰으로 바꿨어요.
초대 링크를 다시 받거나, 별칭과 비밀번호로 들어가면 내역이 그대로 있어요.
홈 화면 아이콘으로 여니 처음 화면이 나와요.
연결 칸에 별칭을 넣고 비밀번호를 넣으세요. 아이폰은 초대 링크를 한 번 더 붙여넣어도 돼요.

2구글 시트 가계부

"보낼 것 N건"이 계속 남아 있어요.
인터넷을 확인하고 위쪽 글자를 눌러 보세요. 휴대폰에는 안전하게 저장돼 있어요.
가족이 적은 게 안 보여요.
상대방 휴대폰이 인터넷에 연결돼야 올라와요. 위쪽 글자를 누르면 바로 주고받아요.
비밀번호를 잊었어요.
"다른 사람 것도 입력"에 체크된 가족이 설정에서 초기화하면 다시 이름으로 돌아가요.
시트 코드가 새로 나왔대요.
Apps Script에 새 Code.js를 붙여넣고(비밀번호 줄 다시 고치기) 저장 → 배포 → 배포 관리 → ✎ → 버전: 새 버전 → 배포. 주소는 그대로예요.
가족 비밀번호를 바꾸고 싶어요.
Apps Script의 FAMILY_CODE를 바꾸고 setup을 다시 실행해요. 가족에게 새 초대 링크를 보내 주세요.

3각자 가계부

가족 내역이 예전 것이에요.
그 사람에게 새 통합용 파일을 다시 보내 달라고 하세요.
🎤 버튼이 안 보여요.
음성 인식이 없는 브라우저(삼성 인터넷·파이어폭스 등)예요. 크롬이나 사파리로 여세요.
마이크 권한을 거절했어요.
주소창 옆 자물쇠(아이폰은 설정 → 사파리 → 마이크)에서 허용으로 바꿔요.
새 휴대폰으로 바꿨어요.
예전 휴대폰에서 설정 → 전체 백업 → 새 휴대폰에서 백업 불러오기. 가족 통합 보기에서도 같은 사람으로 이어져요.

세 가계부 공통

잘못 지웠어요.
바로 아래에 뜨는 되돌리기를 누르세요. 지나갔다면 백업 파일로 되살릴 수 있어요.
홈 화면에 앱으로 두려면?
안드로이드: 더보기 → 홈 화면에 앱으로 설치(없으면 크롬 ⋮ → 홈 화면에 추가). 아이폰: 사파리 공유(□↑) → 홈 화면에 추가.
세 가계부끼리 내역을 옮길 수 있나요?
한 가계부에서 CSV 내보내기 → 다른 가계부의 엑셀·다른 가계부 가져오기로 넣으면 돼요.
우리집 가계부 3종 사용설명서 · 2026년 11월 기준 · 각 앱의 더보기 → 사용법에도 같은 안내가 있어요.
